# Proyecto-ecommerce
Proyecto de e-commerce de creaciones tejidas a mano
# Flancrochetera

## Descripción
Este proyecto es un **sitio web de e-commerce** donde se muestran creaciones tejidas a mano, como amigurumis y prendas. Los usuarios pueden ver productos, detalles de cada producto y agregarlos a un carrito de compras.

## Funcionalidades
- Página de inicio con bienvenida y descripción del proyecto.
- Página de productos donde se listan todos los artículos.
- Página de detalle de producto con opción de agregar al carrito.
- Carrito de compras con actualización dinámica de cantidad y total.
- Contador de carrito persistente usando `localStorage`.

## Tecnologías empleadas
- HTML5 y CSS3 para la estructura y estilos.
- JavaScript (vanilla) para la lógica de productos y carrito.
- Bootstrap 5 para estilos y componentes responsive.
- LocalStorage para persistencia del carrito.
